# Medical Tracking System - Project Report

## 1. Introduction
The Medical Tracking System is designed to efficiently manage patient records, medical history, appointments, and medicine inventory. This system helps hospitals/clinics to digitize patient data.

## 2. Objective
- To store patient details securely
- To track medical history and prescriptions
- To manage doctor appointments
- To maintain medicine stock and reports

## 3. Technologies Used
- Frontend: HTML, CSS, JavaScript / React
- Backend: Python / Node.js
- Database: MySQL / MongoDB
- Version Control: Git & GitHub

## 4. Modules
1.  **Patient Module:** Registration, Profile Management
2.  **Doctor Module:** Doctor availability, Patient assignment
3.  **Appointment Module:** Booking and Scheduling
4.  **Pharmacy Module:** Medicine tracking
5.  **Admin Module:** User management and Reports

## 5. System Features
- Secure Login for Patient, Doctor, Admin
- Add / View / Update / Delete patient records
- Appointment notification
- Medical history tracking
- Report generation

## 6. Conclusion
This system reduces manual paperwork and improves efficiency in medical data management. It can be extended with features like online consultation and payment integration in future.
