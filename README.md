# Medical Tracking System

A simple web-based system to track medical records, patient details and medicine stock.

## Features
- Add / View / Delete Patient Records
- Track Medicine Inventory
- Search Patients by Name/ID
- Dashboard with total counts
- Responsive Design

## Tech Stack
- HTML, CSS, JavaScript
- GitHub Pages for hosting

## How to Run
1. Open index.html in browser
2. Or visit Live Link
